# ASPDC Student Academic & Career Record Portal

This folder contains the complete, production-ready website created using pure **HTML, CSS, and Vanilla JavaScript**.

## 📁 Files in This Folder:
* **`index.html`** - The main webpage containing all sections (Profile, Academic Year Journey, Results/Marksheets, Internships, Clubs, Hackathons, Certifications, Projects).
* **`style.css`** - Master stylesheet with dark theme, glassmorphism, responsive mobile/desktop grids, and official print formatting.
* **`app.js`** - Dynamic frontend dataset and interactive logic (marksheet semester tabs, animations, certificate previews).
* **`Launch_Website.bat`** - Double-click this file anytime to immediately open the website in your browser.

## 🚀 How to Open:
1. Double-click **`Launch_Website.bat`** or **`index.html`**.
2. It opens directly in Google Chrome, Microsoft Edge, Brave, or Firefox.
3. No installation or server needed!
